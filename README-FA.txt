HERAT HEALTH — پروژه اندروید برای ساخت APK سامسونگ

این ZIP پروژه سورس اندروید است؛ خود APK کامپایل‌شده داخلش نیست.
اپلیکیشن محتوای HTML را از داخل بسته اجرا می‌کند، پس صفحه اصلی و جست‌وجوی محلی اینترنت لازم ندارند.
بازکردن نقشه/لینک بیرونی و تماس به اینترنت یا برنامه‌های دیگر دستگاه نیاز دارد.

روش آسان ساخت APK با GitHub Actions:
1) در GitHub یک repository جدید بساز.
2) همه فایل‌های این پوشه را در repository آپلود کن و در شاخه main ذخیره کن.
3) به تب Actions برو و workflow با نام Build Herat Health APK را اجرا کن.
4) پس از پایان موفق، از بخش Artifacts فایل Herat-Health-debug-APK را دانلود کن.
5) ZIP مربوط به artifact را روی کامپیوتر/موبایل استخراج کن؛ فایل app-debug.apk داخل آن است.
6) APK را به گوشی سامسونگ منتقل کن و نصب کن. اگر گوشی اجازه نصب از این منبع را خواست، فقط در صورت اطمینان از منبع فایل اجازه بده.

روش Android Studio:
- پوشه را در Android Studio باز کن.
- اجازه بده Gradle Sync و SDK موردنیاز نصب شود.
- Build > Build Bundle(s) / APK(s) > Build APK(s)
- خروجی معمولاً در app/build/outputs/apk/debug/app-debug.apk است.

نکته:
- APK دیباگ برای آزمایش است؛ برای Google Play باید نسخه release امضا‌شده و معمولاً AAB ساخته شود.
- فهرست مراکز، شماره‌ها و نشانی‌ها قبل از انتشار عمومی باید از منابع معتبر بررسی شوند.
- این پروژه برای نصب و آزمایش آماده‌سازی شده، اما در این محیط APK نهایی کامپایل نشده است.
